# NADIN-NOV-REACT2025Q3

## Project Overview

This is a React application built with TypeScript and Vite.
It features a character search using the Rick and Morty API with pagination.

---

## Technology Stack

- React 19.1
- TypeScript 5.8
- Vite (build tool and dev server)
- ESLint
- Prettier for code formatting
- Husky

## API

The app interacts with the external [Rick and Morty API](https://rickandmortyapi.com/) through the `ItemsApi` class (`src/api/itemsApi.ts`).

## Getting Started

### Clone the repository

git clone <https://github.com/Nadin-Nov/REACT2025Q3.git>

### Install dependencies

`npm install`

### Run the development server

`npm run dev`

### Build the project for production

`npm run build`

## Code Quality Commands

### Check code with ESLint

`npm run lint`

### Fix ESLint errors automatically

`npx eslint . --fix`

### Format code with Prettier

`npm run format:fix`
